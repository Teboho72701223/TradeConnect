# TradeConnect

## Project Description

TradeConnect is a proposed home maintenance and repair services website.
The website provides customers with information about available services
and gives them an easy way to contact the business.

## Purpose

The purpose of TradeConnect is to provide customers with clear information
about home maintenance and repair services and make it easier for customers
to contact the business when they require assistance.

## Services

TradeConnect provides the following services:

- Plumbing
- Electrical Services
- Painting
- Tiling
- Carpentry
- General Home Maintenance

## Website Pages

The website contains the following pages:

- Home
- Services
- About Us
- Our Work
- Contact

## Technologies Used

- HTML5
- Visual Studio Code
- Git
- GitHub

## Website Features

- Multi-page website
- Navigation menu
- Service information
- About Us information
- Work/project showcase
- Contact information
- Service enquiry form
- Relevant images
- Semantic HTML5 structure
- HTML comments
